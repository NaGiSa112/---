## 五、我们会怎么评你的模型

全部用统一口径，命令与判据写在 [T2](T2_异构成员测试协议.md) 里，可自行复算：

```bash
# 1) 你把逐图概率交给我们 → 我们跑
python ../tools/e1_score_v2.py --probs <你的 valid 逐图概率>.csv --name <名字>

# 2) 若 valid 上有信号 → fold2 更高分辨率确认
python ../tools/e1_score_v2.py --probs <你的 fold2 逐图概率>.csv --name <名字>_fold2
```

**判据（预算规则，非实验规律）**

| 门槛 | 阈值 |
|---|---|
| 单模检查级宏 AUC | ≥ 0.8200 |
| 与三只 Tiny 的平均 Spearman（**全 10 类**） | < 0.900 |
| 加进四成员集成的 Δ | ≥ +0.0015 |

> 单模弱于 0.82 仍有救：CAFormer 单模 0.8049 却拿到 +0.0011（valid）/ +0.0037（fold2）。
> **相关性比强度更重要。**
