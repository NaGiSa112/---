## 为什么瞄类 1

| 项 | 值 |
|---|---|
| 类 1 = 纵隔心影增大 | 十类最弱：单只 Tiny 五折 OOF **0.6955** |
| 交付集成在 valid 的类 1 | **0.767315**（固定口径：逐图融合后聚合） |
| fold2 上 Tiny 的类 1 | **0.676230** ← T3a 的真正对照 |
| 宏权重 | 1/10 ⇒ 类 1 涨 **0.010** = 宏涨 0.001 |
| 阳性样本 | fold2：119 检查 / **114 患者**（主终点）；valid：35 图 / 24 检查 / **16 患者**（只作旁证） |

**注意**：`0.6955 → 0.75`（宏 +0.0055）不是这套系统的空间 ——
新头在融合里只占 **16%**，融合后要涨 0.010，新头自己得比旧头好出一截。

## 三组对照（不是只做一个头）

同一批冻结空间特征、同一套融合与聚合：

| 组 | 可训练参数 | 回答什么 |
|---|---:|---|
| **G0 原头** | 0 | 现有类 1 排序 |
| **G1 只学偏置** | **1** | 只调概率水平能拿多少 |
| **G2 完整共享头** | **769** | 重学通道权重能否在 G1 之上再改善 |

**只有 G2 在另一折仍超过 G1，收益才能归给"特征重加权"。**
若 G2 ≈ G1，一个标量就够了 —— 那不是专家，是校准项。

## 实现要点（顺序不能错）

```
build_model → 载入该折 last.pt → 复制已训练的类 1 权重 → model.eval() 并保持 → 冻结其余 → 每轮不调 train()
```

- **载入必须在复制之前**，否则新头拿到随机权重
- **必须 `eval()`**，否则通道 dropout 打开，训练与验收不是同一条特征
- 标签用**原始类 1 硬标签**，显式关掉患者平滑 / 标签平滑 / 蒸馏

### 六项接入检查（全过才开跑）

| # | 检查 | 期望 |
|---|---|---|
| 1 | 新头初始化 vs 旧类 1 输出 | 差 0 |
| 2 | 主干与旧头梯度 | 全 `None` |
| 3 | 可训练参数 | G0=0 / G1=1 / G2=769 |
| 4 | 50 步后新头权重 | 变了 |
| 5 | 50 步后原模型权重 | 完全未变（差 0） |
| 6 | 同一前向里的其他九列 | 与旧头逐值相同（**不要比历史 CSV**，重推已有 9.2e-3 差） |

## 判据（预注册）

**行 1**：新头单独 vs 旧头的类 1 Δ（诊断）
**行 2**：按 16% 掺进融合后的类 1 Δ（**唯一用于升级**）

| 阶段 | 门槛 |
|---|---|
| fold2 → 是否花 fold3 | 行 2 点估计 ≥ **+0.005**（⇔ 宏 +0.0005）且九列差为 0；区间跨零可记「待确认」 |
| fold3 → 是否可重复 | 换 fold3 自己的 Tiny 起点（**需要 fold3 的 CAFormer 概率，当前没有**；若 CAFormer 不进包就不要把它焊进读数） |
| **迁移交付包** | 行 2 ≥ **+0.010** 且患者级区间**整段 > 0** |
| **T3b 独立专家** | 只在「训练损失明显下降但 fold2 Δ 仍跨零/为负」时讨论；且**若替换 Tiny 必须重算十类宏**，不能用"类 1 Δ ÷ 10" |
