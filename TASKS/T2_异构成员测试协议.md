## 二、为什么需要异构成员

交付集成 = 3 只 `ConvNeXt-Tiny`（544） + 1 只 `EfficientNet-B3`（384）。贡献不由强度决定：

| 成员 | 单模检查级宏 AUC | 与三只 Tiny 的 Spearman | 留一贡献 |
|---|---:|---:|---:|
| Tiny seed44 | 0.8200 | — | −0.0006 |
| Tiny pat_s43 | 0.8191 | 0.95–0.96（彼此） | −0.0003 |
| Tiny pat_e12 | 0.8189 | 0.95–0.96（彼此） | −0.0002 |
| **供体 B3** | **0.8129** | **0.82** | **−0.0041** |

**最弱的成员贡献最大。** 三只 Tiny 本质是同一个模型（相关 0.95+），再加多少只都没用。

### 已经试过并失败的（不要重复）

| 方向 | 结果 |
|---|---|
| 同族换尺度（`@640` 上采样 / `@448`） | 单模 0.81 左右，相关 0.93–0.95，**Δ 为负** |
| 同族换几何（letterbox 保比例 / 不裁剪 / 两者合并） | 预注册判据全不过，宏 AUC 还略降 |
| 同族换损失（ASL，侧重难负样本） | 单模 0.7913（最独特 0.8514），但太弱，Δ −0.0007 |
| `Swin-T`、`CAFormer` 12 轮 | 见下表；`Swin-T` 相关 **0.953** 直接判死 |
| 容量（`ConvNeXt-Small` / `Base`） | 两次为负 |
| 折模型 bagging / 权重 soup | −0.0098；他队亦为负 |

**⇒ 唯一有效的路径是「真的不一样」的模型。请优先交你看得见差异的骨干。**

## 三、交付格式（必须严格一致）

### 3.1 逐图概率 CSV

| 文件 | 行数 | 列 |
|---|---:|---|
| `valid_probs.csv` | **1,422** | `Dicom_id,Subject_id,Study_id,p1..p10` |
| `fold2_probs.csv` | **6,150** | 同上 |

要求：

- 一行一张图，`Dicom_id` 与官方 `valid.csv` / `train.csv` 完全一致（不重不漏）
- `p1..p10` 是 `sigmoid` 后的概率，∈ (0,1)，全部有限值
- **必须含水平翻转 TTA**（翻转前后各一次，取平均）
- **不要做任何后处理**：不要检查聚合、不要患者收缩、不要侧位加权 —— 那些由我们统一算

### 3.2 权重与配置

- `last.pt`（**固定末轮**，不挑"最好"的 epoch）
- 提交号、骨干名、输入尺寸、缓存尺寸、**是否蒸馏**、随机种子、轮数
- 预训练权重来源 + `SHA-256`
- 归一化方式（我们默认 `per_image`）
- **推理几何必须与训练几何一致**：拉伸就拉伸、letterbox 就 letterbox

> 我们踩过这个坑：用错几何把 `letterbox` 模型的 0.8138 报成了 0.8122。

### 3.3 训练约束

| 项 | 要求 |
|---|---|
| 折 | **folds `0,1,3,4` 训练，fold 2 留出**（24,194 / 6,150 图） |
| 患者隔离 | 必须，患者不得跨折 |
| 官方 `valid` / `test` | **绝不参与训练或模型选择** |
| 轮数 | 12 轮（取末轮），除非另有说明 |
| 蒸馏 | 首折**不用**（保持与干净 OOF 基线可比） |
| 增强 | 沿用仓库配方：512 拉伸缓存、随机裁剪（面积 0.75–1.0、比例 0.85–1.18）、翻转 0.5、旋转 0.35 / ±7°、擦除 0.25、`mixup`/`cutmix` 0.2 |

> 注：亮度/对比度增强在逐图标准化后会被完全抵消（实测残差 `7e-7`），设了也没用。

## 四、我们会怎么评（你可以先自己跑）

```bash
python ../tools/e1_score_v2.py --probs valid_probs.csv --name <你的模型名>
```

输出三件事：

| 输出 | 含义 |
|---|---|
| 单模检查级宏 AUC | 强度 |
| 与三只 Tiny 的全 10 类 Spearman 均值 | 相关性 —— **这才是关键** |
| 添加权重 0.05–0.60 的 Δ 曲线 | 集成增益（注意峰值在哪、有没有回头） |

### 三条门槛（预算规则，不是实验规律）

| 门槛 | 阈值 | 备注 |
|---|---|---|
| 单模宏 AUC | ≥ 0.8200 | 弱一点仍可谈 |
| 全 10 类 Spearman | **< 0.900** | 硬门槛，相关太高等于白加 |
| 添加 Δ 峰值 | ≥ +0.0015 | 低于此不值得部署成本 |

**若官方 `valid`（859 检查 / 228 患者）上有信号，我们会要你补 `fold2_probs.csv`** ——
fold 2 有 3,706 检查 / 2,211 患者，配对样本大约 9 倍。

## 五、预注册纪律（避免事后挑）

| 禁止 | 原因 |
|---|---|
| 挑"最好"的 epoch | 实测：图像级最优的 ep14 在部署口径上比 ep24 差（0.8026 vs 0.8049） |
| 挑融合权重峰值 | fold 2 上事后挑到 `w=0.40` 给 +0.0044；预注册 `w=0.20` 只有 +0.0037 |
| 只报最好的一折 | 必须报全部折 |
| 只报宏 AUC | 必须同时报逐类，尤其是类 1 / 4 / 8（弱类） |

## 六、参考：已测候选的完整数据

| 候选 | 单模 | Spearman | 最佳添加 Δ | 结论 |
|---|---:|---:|---:|---|
| **`CAFormer-S18` 24 轮** | 0.8049 | **0.8847** | **+0.0011** | 唯一正贡献，待五折 |
| `CAFormer-S18` 12 轮 | 0.8008 | 0.9245 | −0.0001 | 训不够，相关太高 |
| `CAFormer-S18` 16 轮 | 0.8048 | 0.9136 | +0.00003 | 日程不对，相关回升 |
| `Swin-T`（带 KD） | 0.8113 | **0.9532** | −0.0001 | 与 Tiny 同质，判死 |
| `Tiny@640`（上采样） | 0.8111 | 0.9389 | −0.0002 | 同族，无价值 |
| `Tiny` 不裁剪 | 0.8105 | 0.9346 | −0.0001 | 同上 |
| `Tiny` letterbox | 0.8138 | 0.9455 | −0.0001 | 同上 |
| `Tiny` + ASL | 0.7913 | 0.8514 | −0.0007 | 够独特但太弱 |

**规律：相关 0.93+ 的候选，单模再高也没用；相关 0.85–0.88 的候选，即使弱 0.015 也可能有正贡献。**

## 七、术语表（避免译名混淆）

| 术语 | 含义 |
|---|---|
| `fold2_probs.csv` | fold 2 留出集的逐图概率，6,150 行 |
| `last.pt` | 训练末轮的权重 |
| `TTA` | 测试时增强；本项目指水平翻转平均 |
| `Spearman` | 两个模型对同批检查的排序相关系数（全 10 类平均） |
| 添加 Δ | 把候选按权重 w 混进现有集成后，宏 AUC 的增量 |
| 半幂融合 | `0.5 × Σ(w·p) + 0.5 × √Σ(w·p²)`，权重和为 1 |
