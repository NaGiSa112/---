## 首折协议（三人都用同一套，便于横向比）

| 项 | 值 |
|---|---|
| 训练折 | folds `0,1,3,4` = **24,194 图** |
| 留出折 | **fold 2** = 6,150 图 / 3,706 检查 / 2,211 患者 |
| 患者隔离 | 必须零交叉（用仓库内折表，`SHA-256` = `5b0cf113…`） |
| 轮数 | 12 轮，取末轮 |
| 随机种子 | 42 |
| 蒸馏 / EMA / 辅助分支 | **全部关闭** |
| 输入 | 512 拉伸缓存、逐图标准化、LSE `α=0.25`、`τ=1` |
| 学习率 | 主干 `1e-4` / 头 `1e-3` / `weight decay 0.1` / warmup 2 轮 |
| 384 变体 | 在上述缓存上缩放的**单独配置**，需在 PR 中注明 |

### 6 GB 卡需要梯度累积

- 物理 batch 2，累积 8 次 → 等效 16
- 损失按**实际累计样本数**归一化
- 优化器步、`GradScaler`、学习率与 warmup 按**优化器步**计
- 说明每轮末尾不足一组怎么处理
- `BatchNorm` 统计与 `Mixup`/`CutMix` 配对仍由**物理批量**决定

## 我们拿到后会做什么

1. 跑 `../tools/e1_score_v2.py` → 单模检查级宏 AUC / 全 10 类 Spearman / 添加权重曲线
2. 与同折 Tiny（fold 2 单模 **0.810430**）做**两模型半幂融合**，看 Δ
3. 过预注册判据 → 才补 fold 3（该折所有成员换成没见过 fold 3 的权重）
4. 两折同向 → 才谈真实四成员上的追加或替换

判据、格式、预注册纪律见 [T2](T2_异构成员测试协议.md)。
