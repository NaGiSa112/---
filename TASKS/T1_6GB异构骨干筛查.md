## 首折协议（统一，便于我们横向比）

| 项 | 值 |
|---|---|
| 训练折 | folds 0、1、3、4 = **24,194 图** |
| 留出折 | **fold 2** = 6,150 图 / 3,706 检查 / 2,211 患者 |
| 患者隔离 | 必须零交叉（用仓库内折表，SHA `5b0cf113…`） |
| 轮数 | 12 轮取末轮 |
| seed | 42 |
| 蒸馏 / EMA / 辅助分支 | **全部关闭** |
| 输入 | 512 拉伸缓存、逐图标准化、LSE α=0.25 / τ=1 |
| 学习率 | 主干 1e-4 / 头 1e-3 / wd 0.1 / warmup 2 轮 |
| 384 变体 | 在上述缓存上缩放的**单独配置**，需注明 |

**6 GB 卡需要梯度累积**：物理 batch 2 累积 8 次（等效 16）。损失按实际累计样本数归一化；优化器步、GradScaler、学习率与 warmup 都按**优化器步**计；并说明每轮末尾不足一组的处理。BatchNorm 统计与 Mixup 配对仍由**物理批量**决定。
