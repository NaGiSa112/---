> **本仓库不含模型权重与数据集**（体积过大，且受赛方规则约束）。权重与数据在本地保留，
> 仓库只提供可复现的分析、校验与训练/推理代码。
> 文件清单与 SHA-256 见 [`MANIFEST.md`](MANIFEST.md)。

## 四、评测基建（本仓库的核心价值）

实验结论是否可信，取决于尺子。这里有四件东西：

### 1. 冻结的患者五折表

`data/patient_folds_5f.json` / `.csv`：18,513 检查 / 11,055 患者，**每折 2,211 人**，
患者不跨折，类别阳性患者数差 ≤2。折表与训练 seed 解耦 —— 换 seed 不会换折，
所以两次实验是真正配对。

### 2. 统一指标：检查级宏 AUC

`tools/study_metric.py`。交付版 valid 复算 **0.82519454845**，与冻结包记录差 2.55e-13。
（早期曾误用**图像级**数字 0.8313，已更正。）

### 3. 训练可复现性（实证）

同配方、同缓存、同端点、同 seed 连跑两次：

| 检查 | 结果 |
|---|---|
| 权重张量 | 180 个全部比较，最大差 **0.000e+00**，0 个有差异 |
| valid 预测 CSV | **SHA-256 完全相同**（`55333acf…`） |
| 检查级宏 AUC | 两次均 0.8158896578 |

⇒ 控制住配方后，A/B 对照是干净的，不必靠统计压噪声。
详见 [`docs/39_逐位复现记录.md`](docs/39_逐位复现记录.md)。

### 4. 预测完整性检查

`tools/verify_predictions.py`：按折表构造精确预期键集，检查每折 study 不多不少、
每 study 恰好 10 类、拒绝重复/缺失/额外/NaN/越界、患者不跨折，并打印每个文件 SHA。
`tools/compare_folds.py` 已接入：不通过就 abort，不再静默取交集。

## 五、实验结果汇总（10 负 1 弱正）

### 负结果

| # | 假设 | 改动环节 | 宏 Δ | 数据范围 |
|---|---|---|---:|---|
| 1 | 模型靠烧录文字/边框 | 预处理 | −0.0032 | valid 859 |
| 2 | 提高输入分辨率（512→768） | 尺度 | −0.0197 | fold0 3,712 |
| 3 | 左右对称差分通道 | 输入 | −0.0000 | OOF 18,513 |
| 4 | Swin-T 跨架构成员（5%） | 结构 | −0.0002 | valid 859 |
| 5 | 逐类患者收缩（LOFO） | 后处理 | +0.0001 | OOF 18,513 |
| 6 | 类 4↔8 软标签 | 训练目标 | −0.0004 | OOF 18,513 |
| 7 | ImageNet-22K 预训练 | 预训练来源 | −0.0016 | fold0+1 7,401 |
| 8 | 类 1 训练平滑 0.30→0.10 | 训练目标 | −0.0001 | fold0+1 |
| 9 | 折模型 bagging | 集成 | −0.0098 | valid 859 |
| 10 | DINOv2 通用自监督表征 | 表征 | **−0.0258（类1）** | fold2 3,706 |

### 弱正结果

仅类 2 用患者收缩 0.50（其余 9 类 0.85）：

| 路径 | 宏 AUC（0.85） | 宏 AUC（0.50） | Δ |
|---|---:|---:|---:|
| OOF 五折 18,513 检查 | 0.81470 | 0.81506 | **+0.00036** |
| 部署 valid 859 检查 | 0.82519 | 0.82603 | **+0.00083** |

不变性：其余 9 类逐值最大差 **0.000e+00**；单检查患者差 <1e-12。
但 OOF 五折里 fold 3 为负、净收益 71% 来自单一患者 ⇒ 归为"候选"，未上线。

## 六、部署配方

| 项 | 值 |
|---|---|
| 结构 | 3 × ConvNeXt-Tiny（输入 544，LSE 池化 α=0.30、τ=1.0）+ EfficientNet-B3 供体（384，权重 0.15） |
| 融合 | 半幂：`0.5×加权算术均值 + 0.5×加权 RMS` |
| TTA | 水平翻转（折叠进 batch=2） |
| 后处理 | 侧位权重 0.6 → 检查内加权均值 → 患者收缩 `p = 0.85·p_study + 0.15·p_患者均值` |
| 训练配方 | BCEWithLogits、AdamW（backbone 1e-4 / head 1e-3，wd 0.1）、2 轮 warmup + cosine、12 轮、batch 16、drop_path 0.15、mixup/cutmix 0.2、erase 0.25、旋转 7°、患者标签平滑 0.3、软标签蒸馏 0.5 |

## 七、如何复现

### 环境

Python 3.11+、PyTorch 2.9 + CUDA 12.8、torchvision 0.24、NumPy / pandas / Pillow / scipy、pypdf、safetensors、scikit-learn。

### 评估（只需预生成的预测 CSV）

```powershell
$env:PYTHONPATH = "<repo>/.pylibs;<repo>/src"
$env:CXR_DATA   = "<data>/cxr_first"

python tools/study_metric.py runs/orig_valid.csv
python tools/verify_predictions.py --tag oof --folds 0,1,2,3,4
python tools/compare_folds.py --tag <候选tag> --folds 0,1,2,3,4 --boot 2000
```

### 训练与推理

```powershell
python src/build_cache.py --sizes 512
python src/train.py --arch convnext_tiny --img-size 512 --cache-size 512 --epochs 12 `
    --batch-size 16 --lr-backbone 1e-4 --lr-head 1e-3 --weight-decay 0.1 --warmup-epochs 2 `
    --label-smooth 0.03 --mixup 0.2 --cutmix 0.2 --drop-path 0.15 --ema 0 --workers 0 --amp bf16 `
    --patient-smooth 0.3 --head-type lse --lse-alpha 0.25 --lse-tau 1.0 `
    --erase-prob 0.25 --rbc-prob 0.25 --rot-deg 7 --scale-min 0.75 --seed 42 `
    --fold-csv data/patient_folds_5f.csv --valid-fold 2 --train-folds 0,1,3,4 `
    --out-dir runs/demo --tag demo

python src/predict.py --split valid --deploy model/deploy.json --out runs/demo_valid.csv
```

## 八、已知限制

1. **valid 与 test 的患者结构不同**：每患者图片数 train 2.74 / valid 6.24 / test 16.31，
   valid 上 52% 患者只有一次检查，test 只有 8%。患者级后处理在 valid 上难体现。
2. **Kish 有效样本量**：valid 的 859 检查折算有效患者约 45 名 —— 绝对 AUC 的置信区间很宽，
   单次抽样不能作为"改进有效"的证据。
3. **折与 valid 已被反复使用**：本仓库所有"新结果"都是**复用验证**，不是独立确认。
4. **蒸馏教师泄漏**：教师在全 train 上训练，因此 OOF 阶段一律 no-KD；
   部署配方（KD）没有干净的 OOF。
5. **DINOv2 探针只在 fold 2 做过**：结论为负，未做第二折确认。
