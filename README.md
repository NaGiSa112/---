> 当前：已入围国赛 ｜ 初赛线上 **78.51** ｜交付版延迟 **51 ms**、权重 **377 MB**、合规审计 **29/29**

## 一、赛题

给胸片打 10 个类别的多标签，按**检查（study）**输出每类概率，用 10 类平均 ROC-AUC 评分。

| 项 | 内容 |
|---|---|
| 输入 | 单张胸片（grayscale），同一检查可能有多个视角（AP / PA / LL） |
| 输出 | 每个检查 10 个概率，提交列为 `Predict_class` + 概率 |
| 指标 | 10 类平均 ROC-AUC（检查级，平台百分制） |
| 数据 | train 30,344 图 / 18,513 检查 / 11,055 患者；valid 1,422 / 859 / 228；test 2,218 / 1,414 / 136 |

### 硬约束

| 约束 | 内容 |
|---|---|
| 预训练 | 仅允许**通用自然图像**权重（ImageNet / COCO / LAION 级）；医学影像预训练属严重违规 |
| 数据 | 只能用赛方数据；测试集不得用于训练、调参、阈值选择、统计量估计、伪标签 |
| 体积 | 推理时加载的权重 ≤ **500 MB** |
| 延迟 | 单张端到端 ≤ **100 ms**（batch=1，含读图与预处理） |

## 二、仓库重点：让结论站得住

多标签比赛的常见陷阱不是模型不够大，而是**尺子不稳**：用图像级数字冒充检查级、
预测文件缺格却静默取交集、折表随 seed 变化、拿单折结果和五折结果并列比较。
这里用四件东西挡住这些问题。

**① 冻结的患者五折表**
18,513 检查 / 11,055 患者，**每折 2,211 人**，患者不跨折，类别阳性患者数差 ≤2。
折表与训练 seed 解耦 —— 换 seed 不换折，两次实验才真正配对。

**② 统一指标：检查级宏 AUC**
交付版 valid 复算 `0.82519454845`，与冻结包记录差 2.55e-13。
（项目早期曾误用图像级 `0.8313`，已更正并在所有旧报告加横幅。）

**③ 训练可复现性（实证）**
同缓存、同 batch、同端点、同 seed 连跑两次：

| 检查 | 结果 |
|---|---|
| 权重张量 | 180 个全部比较，最大差 **0.000e+00** |
| valid 预测 CSV | **SHA-256 完全相同** |
| 检查级宏 AUC | 两次均 `0.8158896578` |

**④ 会失败的完整性检查**
按折表构造精确预期键集，拒绝重复 / 缺失 / 额外 / NaN / 越界 / 患者跨折，并打印每个文件 SHA；
下游评测脚本不通过即 abort。

## 三、实验结果一览

在干净的 OOF（单模型、无蒸馏、固定末轮，宏 **0.81470**）上试了 **11 个方向，全部无可采纳收益**：

| # | 假设 | 环节 | 宏 Δ |
|---|---|---|---:|
| 1 | 模型靠烧录文字/边框 | 预处理 | −0.0032 |
| 2 | 提高输入分辨率 512→768 | 尺度 | −0.0197 |
| 3 | 左右对称差分通道 | 输入 | −0.0000 |
| 4 | Swin-T 跨架构成员（5%） | 结构 | −0.0002 |
| 5 | 逐类患者收缩（LOFO） | 后处理 | +0.0001 |
| 6 | 类 4↔8 软标签 | 训练目标 | −0.0004 |
| 7 | ImageNet-22K 预训练 | 预训练来源 | −0.0016 |
| 8 | 类 1 训练平滑 0.30→0.10 | 训练目标 | −0.0001 |
| 9 | 折模型 bagging | 集成 | −0.0098 |
| 10 | DINOv2 通用自监督表征 | 表征 | **−0.0258**（类1） |
| 11 | **CAFormer-S18 异构骨干** | 架构异构 | **集成 Δ −0.000129**（单模 0.8008、全10类 Spearman 0.9245） |

**唯一弱正**：仅类 2 用患者收缩 0.50 → OOF `+0.00036`、部署 valid `+0.00083`；
其余 9 类逐值最大差 `0.000e+00`。但 OOF 五折里有一折为负、收益 71% 来自单一患者，**未上线**。

**弱类**（OOF）：类 1 纵隔心影增大 `0.695` ｜ 类 4 肺炎 `0.733` ｜ 类 8 肺部阴影 `0.754`。
换表征（DINOv2）、换训练目标、换输入通道均不改善 —— 指向**标签可分辨性**，而非方法不足。

| 结构 | 3 × ConvNeXt-Tiny（544，LSE α=0.30）+ EfficientNet-B3 供体（384，权重 0.15） |

## 六、快速开始

```powershell
$env:PYTHONPATH = "<repo>/.pylibs;<repo>/src"
$env:CXR_DATA   = "<data>/cxr_first"

# 预测完整性：不多不少、每检查 10 类、拒绝重复缺失
python tools/verify_predictions.py --tag oof --folds 0,1,2,3,4

# 检查级宏 AUC
python tools/study_metric.py runs/orig_valid.csv

# 任意候选 vs OOF 基线（自带完整性检查与真实 bootstrap 次数）
python tools/compare_folds.py --tag asym --folds 0,1,2,3,4 --boot 2000
```

训练与推理的完整命令见 [`README_详细.md`](README_详细.md)。

## 七、不含什么

| 不含 | 原因 |
|---|---|
| 模型权重（`.pt`） | 交付四成员合计 377 MB，超出仓库合理体积 |
| 数据集 | 赛方数据，受规则约束不可转载 |
| 运行产物（`runs/`、`releases/`、`submissions/`） | 体积大且可再生成，已在 `.gitignore` 排除 |

仓库**未使用**任何医学影像预训练权重，也未使用其它队伍的模型或预测。
第三方仅限公开通用视觉预训练（ConvNeXt / EfficientNet / DINOv2）与常规科学计算库。
