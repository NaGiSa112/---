## 附录 C：术语

- **study / 检查**：提交文件的行单位，可含 1–4 张图（PA / AP / LATERAL / LL）
- **LSE 池化**：`z=(1−α)·mean(M)+α·τ·(logsumexp(M/τ)−log N)`，M 为逐位置 logits
- **患者收缩**：`p = a·p_study + (1−a)·p_患者均值`，推理侧的确定性聚合
- **训练患者平滑**：目标层面 `y' = (1−w)·y + w·y_患者均值`，与上面的推理收缩是两件事
- **OOF**：out-of-fold，用冻结折表训练后对留出折的预测，拼成全量
- **LOFO**：留一折验证，用于估计后处理参数的样本外增益
