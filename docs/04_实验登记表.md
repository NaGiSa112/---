## 四、KD 谱系与「7 小时」的账单口径

- 教师：交付版的 3 个 Tiny 中取两只做软标签教师，`../data/teacher_soft_full_a.csv` 是**全 train** 生成的。
  ⇒ 因此 OOF 阶段一律 no-KD，否则教师见过外层留出折（泄漏）。
- 若要重建「干净部署 OOF」：每折需要 2 个教师 + 3 个学生 + B3 供体，逐折隔离。
  按本表实测单折学生耗时（见上表 `oof_f*` 行）可推算，但**教师训练没有历史记录**，
  所以「7 小时」是**假设值而非实测**，审阅指出这一点是正确的。

| 组成部分 | 是否有实测记录 |
|---|---|
| 学生单折（no-KD） | ✅ 有（见上表） |
| 学生单折（含 KD） | ❌ 无独立记录 |
| 教师单折 | ❌ 无记录 |
| B3 供体单折 | ❌ 无记录（协作方训练） |
| 软标签生成 | ❌ 无计时 |
