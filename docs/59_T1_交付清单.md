### 3. 完整命令行（含种子 / 轮数 / 物理批量）

```powershell
$env:CXR_DATA   = "D:\HLW\cxr_first"
$env:CXR_CACHE  = "D:\HLW\cxr_work\cache_t1"      # 内含 train_512.npy
$env:HF_HOME    = "D:\HLW\cxr_work\hf_cache"
$env:HF_ENDPOINT= "https://hf-mirror.com"
$env:PYTHONPATH = "<repo>/src"

python -m cxr.train --arch hrnet_w18.ms_aug_in1k --img-size 384 --cache-size 512 `
  --epochs 12 --batch-size 8 --accum-steps 2 --seed 42 `
  --lr-backbone 1e-4 --lr-head 1e-3 --weight-decay 0.1 --warmup-epochs 2 `
  --drop-path 0 --ema 0 --amp fp16 --workers 0 `
  --head-type lse --lse-alpha 0.25 --lse-tau 1.0 `
  --mixup 0.2 --cutmix 0.2 --erase-prob 0.25 --rbc-prob 0.25 --rot-deg 7 --scale-min 0.75 `
  --label-smooth 0.03 --patient-smooth 0.3 `
  --fold-csv data/patient_folds_5f.csv --train-folds 0,1,3,4 --valid-fold 2 `
  --out-dir runs_t1/hrnet18_384_f2_accum2
```

- 种子 **42**；轮数 **12**（取第 12 轮）；物理批量 **8** × 累积 **2** = 等效 **16**
- 蒸馏关闭（`distill_weight=0`）、EMA 关闭、辅助分支关闭
- 导出命令见 `docs/58_T1_HRNet-W18_fold2_交付.md` §8

## 二、折表核对（你要求先确认的那条）

**结论：两份折表是同一个划分，SHA 差异只来自行尾符。**

- 你们那份 `5b0cf113…` 的文件 = 本仓库这份 `c465d164…` 的文件在 **LF → CRLF** 转换后的字节：
  把本文件的 `\n` 全部替换成 `\r\n`，SHA-256 精确等于 `5b0cf113345adb4385089a8ee694dad6e5962899f8bb2cbce5f3a36d5d1dea21`。
  （pandas 在 Windows 上写 CSV 默认用 `os.linesep`，所以你们原始文件是 CRLF；zip 打包时被转成了 LF。）
- 用仓库的生成器 `tools/make_patient_folds.py`（`SEED=2026`）重跑并与本折表逐 Study 比对：
  **18,513 个 Study 中折号不一致 0 个**，每折 studies `3712/3689/3706/3695/3711`、
  每折 patients `2211×5` 完全复现。
- 用 `tools/compare_fold_tables.py`（本快照里没有，已补）跑 A=CRLF 版、B=本表：

```
折号不一致的 Study：0
若以 A 的 fold 2 为评估集：B 的训练集里有 0 个 A-fold2 检查
若以 B 的 fold 2 为评估集：A 的训练集里有 0 个 B-fold2 检查
[结论] 两份折表划分一致，无泄漏风险
```

**所以在 fold 2 上的 0.8063（检查级+收缩）不是泄漏后的虚高。**
