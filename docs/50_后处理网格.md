## 4　这套网格能分辨多大的差异

- valid 只有 859 个检查 / 228 名患者；单检查患者占多数，
  患者级聚合的 Kish 有效样本量约 45 名。
- 因此 **±0.001 量级的差异在 valid 上不可分辨**：上表相邻取值之间多数差异落在噪声内。
- 结论：valid 只能用来排除大错（如 a=1 掉 0.0019），不能用来挑 0.0005 级的胜负；
  要挑细微差异必须靠 **OOF 五折**或**线上分数**。
