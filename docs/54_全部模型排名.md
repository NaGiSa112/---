## C　怎么读这两张表

1. **A 表是决策依据** —— 只有它反映「在官方 valid 上的真实强度」。
2. B 表里很多 run 的 0.82+ 与 A 表的 0.80–0.82 不是同一把尺子，别直接比。
3. 交付集成的 0.82519 是 A 表成员**融合后**的结果，单模最高只有 0.8200。
4. 所有 A 表数值属同缓存配对比较（成员基线 0.82535481 vs 冻结 0.82519455，差 +1.6e-4）。
