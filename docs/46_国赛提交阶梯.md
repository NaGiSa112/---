# 国赛 7 天提交阶梯（2026-11-23 定稿）

> 前提（已确认）：**同一测试集** 、**一天一交** 、**取历史最高**
> 结论：掉分不伤 ⇒ 7 次全是"免费测量"，应把每一次都用来测一个方向，而不是保守重复。

## 一、为什么这次能真正"量"出来

| 尺子 | 分辨率 | 说明 |
|---|---|---|
| valid（859 检查） | ~0.01 AUC | Kish 有效患者仅约 45 名，看不见 0.001 级差异 |
| OOF 五折（18,513 检查） | ~0.001–0.002 AUC | 但模型是 no-KD 单模，与交付系统不同分布 |
| **线上分** | **0.0001 AUC（0.01 分）** | 同一测试集 + 确定性推理 ⇒ 无抽样噪声，**精确可测** |

所以：**把后处理旋钮搬到线上去量**，这是本项目唯一分辨率足够的评估方式。

### 决策规则（每天读分后执行）

```
D = 今天分数 − V0 分数        （分辨率 0.01 分）

若 D ≥ +0.10  →  该旋钮方向为真，保留，并在最后一天围绕它细化
若 |D| ≤ 0.05 →  与噪声无差别，放弃该方向
若 D ≤ −0.10  →  该方向有害，反向可能有用（例如 V4/V5 构成括号）
```

最后一格永远交 **7 天里分数最高的那个变体**（因取历史最高，重复提交最优版无风险）。
