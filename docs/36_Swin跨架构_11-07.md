# 2026-11-07 凌晨：合规跨架构成员实验

## 一、实验设置

唯一变量：**架构**从 ConvNeXt-Tiny 换成 Swin-T，其余全部相同。

| 项 | 值 |
|---|---|
| 骨干 | `torchvision` swin_t，ImageNet-1k 权重（**合规**） |
| 池化 | LSE α=0.25，τ=1.0（与主线相同） |
| 蒸馏 | 老师 = 3 个 fold-honest LSE 成员，w=0.5（与主线相同） |
| 数据 | folds 0-2 训练 / fold3 选模 / **fold4 评估** |
| 其余 | 12 轮、mixup/cutmix 0.2、drop_path 0.15、erase 0.25、seed 42 |

为支持 Swin，`src/cxr/models.py` 新增 `_spatial_features()` 适配层
（Swin 的 `features()` 返回 channels-last 的 `B,H,W,C`，且模型不可下标，
原来的 `backbone[0]` 写法只对 ConvNeXt 有效）。

**回归验证**：改动后用旧代码生成的 valid 预测做对照，
`cnxt512_lse_e12` 与 `cnxt640_lse_e12` 的 max |Δp| = **2.98e-08**，数值一致，部署模型未受影响。

## 二、结果：换架构只值 +0.0010

**训练曲线（fold3）**

| epoch | Swin-T | ConvNeXt-Tiny（对照） |
|---|---|---|
| e1 | **0.7673** | 0.7450 |
| e3 | 0.7919 | 0.7860 |
| e5 | 0.7990 | **0.8040** |
| e11（峰值） | 0.8165 | **0.8189** |

Swin 起步更快（ViT 类收敛快），但中段被反超，最终低 0.0024。

**fold4 评估**

| 组 | fold4 AUC |
|---|---|
| kd512 | 0.8113 |
| kd640 | 0.8117 |
| swin512 | 0.8092 |
| **ours = kd512 + kd640** | **0.8133** |
| ours + swin512 | 0.8143 |

```
ours+swin512 − ours = +0.0010   95%CI [−0.0000, +0.0022]   不显著
```

## 三、为什么无效：相关性几乎没动

| 对比 | 相关系数 |
|---|---|
| kd512 vs kd640（**同架构、不同分辨率**） | 0.9844 |
| kd512 vs swin512（**换架构**） | 0.9721 |
| kd640 vs swin512 | 0.9721 |
| lse512 vs swin512 | 0.9699 |
| **我们 vs 队友体系** | **0.51 – 0.75** |

逐类相关（ours vs swin512）：class 5/9/10 为 0.97–0.98，最不相关的 class 1–4 也只有 **0.90–0.91**。

**换架构只把相关性从 0.984 降到 0.972** —— 相对于跨体系的 0.5–0.75，等于没动。

## 四、结论与含义

1. **队友体系的多样性不来自架构，而来自医学预训练（RAD-DINO）+ 不同训练配方。**
   其中贡献最大的一项**恰好是规则第 1 条明令禁止的**。

2. **因此合规范围内无法复制那 +0.0031。** 换架构的贡献（+0.0010）甚至小于
   同架构换 seed（+0.0017），两者都在噪声边缘。

3. **建议停止"加更多合规成员"这条线。** 实测每个架构级成员值 +0.001 量级，
   而部署受 100 ms 限（2 成员），继续投入的回报远低于成本。

## 五、对照参考：那些已经确认的量级

| 改动 | fold4 配对差 | 显著性 |
|---|---|---|
| LSE 池化 | +0.0019 / +0.0025（两 seed） | 一次显著 |
| 知识蒸馏 | +0.0034 / +0.0059（两 seed） | **两次都显著** |
| 同架构换 seed | +0.0017 | 不显著 |
| 换架构（Swin） | +0.0010 | 不显著 |
| 跨团队混合 | +0.0031 | 显著（但来源不合规） |

**目前唯一"显著且合规、可复现"的改进仍然是知识蒸馏。**

## 六、未完成

`v_swin640`（Swin-T @640）仍在训练，结果待补。若它与 swin512 同样只值 +0.001，
则本结论完整；4 成员混合（2 ConvNeXt + 2 Swin）会一并测量，但它无法部署（超延迟）。
