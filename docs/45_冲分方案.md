## 一、这张三联图说了什么

**A　离线涨多少，线上才分得出来？**

我们历史四次提交的（离线 valid 宏 AUC，线上分）配对：

| 提交 | 离线宏 AUC | 线上分 |
|---|---:|---:|
| final_close 11-12 | 0.826337 | 78.42 |
| final_sweep 11-11 | 0.824929 | 78.46 |
| last_chance 11-12 | 0.825972 | 78.46 |
| final_day 11-13 | 0.825195 | **78.51** |

**离线最高的那次（0.8263）线上反而最低（78.42）；离线最低的那次（0.8249）线上并不是最差。**
拟合斜率 −38.4（R²=0.47，n=4，跨度仅 0.0014）—— 这不是"回归"，这是**没有可用映射**的证据。

原因不是线上有噪声，而是：
- **线上分是确定性的**：同一测试集 + 同一模型 → 同一分数，没有抽样波动；
- **valid 的分辨率不够**：859 个检查、228 名患者、Kish 有效样本量约 **45 名患者**。
  我们十次实验的差异（0.0001~0.0016）**全部落在 valid 的噪声内**。

**B　弱类是被数据量限制的吗？**

逐类 OOF AUC 对阳性检查数（对数）拟合：`AUC = +0.057·log10(n) + 0.628`，**R² 只有 0.08**。
样本量几乎解释不了差异：
- 类 1（622 例）比拟合线低约 0.06；
- 同样少的类 2（822 例）、类 5（1,170 例）却有 0.878 / 0.883；
- 类 8（4,508 例，样本充足）只有 0.754。

⇒ 弱类不是"数据不够"，而是**标签本身难判定**。这堵死了"多训几个模型就能救类 1"的路。

**C　名次-分数曲线：冲分的价格**

前 30% 线在第 98 名（78.42）。切线附近约 **0.008 分/名次**；进前 50 要 +0.31 分（≈+0.0031 AUC）。
而我们现成最强候选只值 +0.083 分。

## 二、结论：换尺子，不换模型

三张图指向同一件事：

> 在 valid 上继续找 0.0005 级的改进**没有意义**（看不见）；
> 而线上分是**确定且精确可测**的。

所以最后 9 天的正确做法不是再训模型，而是：
**把后处理的可调空间，搬到排行榜上去量。**

这不是投机，是**唯一分辨率足够的评估方式**。我们此前已经踩过一次红线（本地读 `test.csv` 聚合统计量），
但**用官方排行榜反馈选型是常规且允许的**，两者必须严格区分。

## 三、方案：一次推理 + 后处理扫描 + 每日读数

### Step 1　建立"测试集概率库"（一次性，约 2 分钟 GPU）

对 test 的 2,218 张图跑一次推理，把**逐图、逐类概率**（融合后、侧位加权前、患者收缩前）落盘。
之后所有变体都是 CSV 变换，**秒级生成**，不需要再碰 GPU。

### Step 2　变体生成器（CPU，秒级）

旋钮与 valid 实测幅度：

| 旋钮 | 取值 | valid 宏 AUC | 相对现值 |
|---|---|---:|---:|
| 全局患者收缩 a | 0.85（现） | 0.825195 | — |
| | 0.825 | 0.825294 | +0.00010 |
| | 0.80 | 0.825273 | +0.00008 |
| | 1.00（不收缩） | 0.823293 | −0.00190 |
| 类 2 收缩 | 0.40 | 0.826030 | +0.00084 |
| | **0.45** | **0.826049** | **+0.00086** |
| | 0.50 | 0.826026 | +0.00083 |
| | 0.60 | 0.825977 | +0.00078 |
| 组合（a=0.825 + 类2=0.50） | | 0.825991 | +0.00080 |

**注意类 2 的收益是一段平台（0.40–0.60 都在 +0.0008 左右），不是单点调参** —— 这提高了它"方向为真"的可信度，但仍受 fold-3 为负的制约。

### Step 3　提交阶梯（12-01 ~ 12-07）

| 天 | 提交 | 目的 |
|---|---|---|
| 12-01 | **V0 基线** | 锁住已有分数，零风险 |
| 12-02 | V1 = V0 + 类 2 = 0.50 | 量 +0.0008 是否真兑现 |
| 12-03 | V2 = V0 + 全局 a = 0.825 | 量 ±0.0001（预期无差别，作为噪声对照） |
| 12-04 | V3 = V2 + 侧位权重 0.5 / 0.7 | 这个旋钮我们**从未在 valid 上扫过**，可能有意外 |
| 12-05 | V4 = 供体权重 0.10 / 0.20 | 同上 |
| 12-06 | 组合最优 | 把前几步里真正涨的拼起来 |
| 12-07 | **确认最优版** | 收口 |

**关键纪律**
1. 若官方按**最后一次**计分，前 6 天随便试，第 7 天必须交最优；
   若按**历史最高**，则可放心试。
2. 每次提交前跑 29 项审计（打包、体积、延迟、清单）。
3. 每次读数记录到一张表：变体 / 线上分 / 与 V0 的差 / 是否保留。

## 四、为什么这是最好的选择（而不是再训模型）

| 方案 | 需要的资源 | 预期收益 | 可测性 |
|---|---|---|---|
| 再训一个模型族 | 数十 GPU 小时 | 十个方向全负，最乐观 +0.002 | 只能靠 valid（分辨不了） |
| 折模型 bagging | 已验证 | **−0.0098** | OOF 可测 |
| DINOv2 表征 | 已验证 | **−0.0258（类1）** | OOF 可测 |
| **后处理扫描** | **一次推理 + 每天一次提交** | **已有 +0.0009 在手，且侧位/供体权重尚未扫过** | **线上确定性可测** |

后处理是本项目唯一"收益可测、成本极低、还没有穷尽"的地方。
