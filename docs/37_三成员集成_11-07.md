# 2026-11-07 晚：3 成员部署尝试（失败）与合规现状

## 一、为什么做这个

fold4（2,216 患者）上，把 Swin 成员加到我们的两个 ConvNeXt 成员上：

```
+0.0013   95%CI [+0.0002, +0.0024]   显著
```

这是目前唯一"合规且统计显著"但尚未部署的增益，所以值得试一次：训全量 Swin，
看 3 成员能否压进 100 ms。

## 二、结果：两个理由都否掉了

### 1. 全量 Swin 本身更弱

| 模型 | valid（图级，TTA） |
|---|---|
| cnxt512_kd_e12 | 0.8248 |
| cnxt640_kd_e12 | 0.8258 |
| **cnxt_swin640_kd**（本次训练） | **0.8188** |

低 0.006 —— 与 fold-honest 上"慢 0.002"的结论一致。Swin-T 在 1.8 万张图上确实不如 ConvNeXt-Tiny。

### 2. 延迟超限，且超出很多

| 配置 | 延迟（均值） | 判定 |
|---|---|---|
| 2 成员（当前部署） | 83.71 ms | ✅ |
| **3 成员（+Swin640）** | **121.76 ms** | ❌ 超 21.8 ms |

Swin 成员单个吃掉 **+38 ms**（窗口注意力比 ConvNeXt 慢），不是预估的 +19 ms。

而且**同一份 2 成员配置，不同时段测出 74.9 / 80.1 / 83.7 ms** —— 机器状态带来约 12% 波动。
这意味着即使加一个 +19 ms 的成员（如另一个 ConvNeXt 分辨率），也会落在 103 ms 附近，
**没有安全余量**。

### 3. valid 上也没有改善

| 指标 | 2 成员（78.02） | 3 成员 | 差 |
|---|---|---|---|
| img_raw | 0.8290 | 0.8296 | +0.0006 |
| img_study | 0.8369 | 0.8365 | −0.0004 |
| study | 0.8194 | 0.8190 | −0.0004 |
| AP 单图 | 0.7481 | 0.7488 | +0.0007 |
| post_study | 0.8224 | 0.8212 | −0.0012 |

本质是持平。fold4 上的 +0.0013 在 valid 上没体现（valid 只有 228 患者，分辨不了），
但**既然部署不了，这一点已经无关**。

## 三、结论

**"增加成员"这条合规路线在所有维度上都关闭了：**

| 角度 | 证据 |
|---|---|
| 多样性 | 换架构只把相关性从 0.984 降到 0.972（跨团队是 0.51–0.75） |
| 质量 | 全量 Swin valid 0.8188，低于 ConvNeXt 0.8258 |
| 部署 | 3 成员 121.8 ms，超限 21.8 ms |
| 效果 | valid 上与 2 成员持平 |

**合规可部署的最优仍是 `cnxt512_kd_e12 + cnxt640_kd_e12`（线上 78.02，valid img_raw 0.8290，延迟 74.9–83.7 ms）。**

## 四、这轮修掉的工程问题

队列第一次运行时，`predict`/`latency`/`eval` 三步连续失败，原因是
`Set-Content -Encoding utf8` 在 PowerShell 5.1 下给 JSON 写入了 **BOM**，
Python 的 `json.load` 直接抛 `Unexpected UTF-8 BOM`。
已改为 `[System.IO.File]::WriteAllText` + `UTF8Encoding($false)` 无 BOM 写入。

训练本身是成功的，产物保留：`runs/cnxt_swin640_kd/best.pt`、`submissions/ens3/submission.csv`（候选，未提交）。

## 六、若要继续，只剩一个未验证的方向

测试集 69.4% 的 study 来自"人均 10+ 次检查"的慢性患者，而我们在这一层的 AUC 只有 0.768
（单次检查层是 0.879）。已试过并失败的：过采样（−0.028）、患者级平滑（+0.0005）。

**未试过的是"患者上下文模型"**：把同一患者的其他检查作为额外观测输入，而不是事后平均。
规则补充第 7 条明确允许"对同一患者的多个测试图像做确定性聚合"，所以这个方向合法。
代价是数据管线要改（需要按患者组织多图输入），预计 4–6 小时，且成功率未知。
