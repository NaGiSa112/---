# CAFormer 与 Transformer 的区别（以及"用于医学分割"该怎么理解）

2026-11-24 ｜ 配套：`48_魔搭候选主干.md`

---

## 一、CAFormer 是什么

CAFormer 属于 **MetaFormer** 家族（Yu et al., *MetaFormer Baselines for Vision*, 2022）。
它把骨干抽象成两类模块：**token mixer（混合空间信息）** + **channel MLP（混合通道信息）**，
再用不同的 token mixer 组合出不同模型：

| 模型 | token mixer 组成 |
|---|---|
| PoolFormer | 平均池化 |
| ConvFormer | 全部深度可分离卷积 |
| **CAFormer** | **前两阶段卷积 + 后两阶段自注意力**（Conv + Attention，故得名） |

所以 CAFormer **不是"又一个 Transformer 变体"**，而是"卷积塔 + 注意力塔"的层次化混合体。

---

## 二、与纯 Transformer（ViT）的关键差别

| 维度 | ViT（纯 Transformer） | CAFormer-S18 |
|---|---|---|
| 特征尺度 | **单一尺度**，patch 16，全程同一分辨率 | **4 阶段金字塔**，逐级 2× 下采样 |
| 空间混合 | 每一层都是全局自注意力 | 阶段 1–2 用 7×7 深度可分离卷积；阶段 3–4 用自注意力 |
| 归纳偏置 | 弱（局部性/平移等变靠数据学） | 早期卷积提供局部性与平移等变 |
| 算力增长 | 注意力 O((HW)²)，544 输入下 1,156 tokens 已很吃紧 | 自注意力只在 17×17、9×9 的小图上做 |
| 小数据适应性 | 需要大数据或强预训练 | 中等数据更稳（卷积先验兜底） |
| 预训练范式 | 通常监督/自监督大模型 | ImageNet-22K + SAIL 蒸馏即可 |

**一句话**：ViT 是"全用注意力、单尺度"；CAFormer 是"前面卷积打底、后面注意力收尾、多尺度输出"。

## 三、在我们这次训练里，实际差别是三处（都可控）

### 1. 输入通道改造（对我们更容易）

我们的 `_adapt_first_conv` 做的是：把 ImageNet stem 的 **3 通道卷积权重压成 1 通道**
（灰度输入），或额外加零初始化通道（B1 实验用过）。

- ConvNeXt：`stem[0]` 是 4×4 conv(3→96) → 改 1 通道，已验证逐位等价。
- **CAFormer：SepStem = 3×3 depthwise + 1×1，第一层就是 3 输入卷积** → 改法与 ConvNeXt 同型。
- ViT：`patch_embed` 也是 conv，但**后面没有金字塔**，我们接不上 LSE 头（见下）。

### 2. LSE 头需要"分类器前的空间特征图"

我们的头是 `LSE(空间图, α=0.30)` 而不是全局平均池化。这要求模型能吐出特征图：

| 模型 | 544 输入下末级特征图 |
|---|---|
| ConvNeXt-Tiny | 17×17 × 768 |
| **CAFormer-S18** | **17×17**（4 阶段，末级 stride 32） |
| ViT-B/14 | 无金字塔，只有 32×32 token 序列 |

⇒ CAFormer 的空间图尺寸与我们**完全一致**，LSE 头可原封不动套用；ViT 需要额外改造。

### 3. 算力与延迟（实测，544 输入、bf16、batch=1）

| 骨干 | 参数 | 延迟 | 相对 Tiny |
|---|---:|---:|---:|
| **ConvNeXt-Tiny（现用）** | 27.8M | **14.5 ms** | 1.00× |
| ConvNeXtV2-Tiny | 27.9M | 20.8 ms | 1.43× |
| **CAFormer-S18** | 24.3M | **26.7 ms** | **1.84×** |
| CAFormer-S36@384 | 37.3M | 51.5 ms | 3.55× |
| EfficientViT-B1 | 7.5M | 28.8 ms | 1.99× |

（SwinV2 / MaxViT / CoAtNet 在 544 下因窗口/切块整除约束直接报错，需补 padding 才能测。）

**含义**：CAFormer-S18 单独 26.7 ms，我们现包四成员端到端 51 ms。
若直接并联成第 5 成员，叠加 TTA 后大概率**突破 100 ms**。两条可行路径：

| 方案 | 体积 | 延迟估算 | 代价 |
|---|---:|---:|---|
| CAFormer@448 作第 5 成员 | 474 MB | ~80 ms | 分辨率低于其他成员 |
| **去掉一个冗余 Tiny + CAFormer@544** | 363 MB | ~83 ms | 留一损失仅 0.0002~0.0006 |

第二条更有吸引力：三个 Tiny 之间 Spearman 0.95–0.96 本就高度冗余。

## 四、"CAFormer 用于医学图像分割"该怎么理解

这里要**把架构和权重分开**，否则会误踩规则：

| 层面 | 说明 | 是否违规 |
|---|---|---|
| **架构**（CAFormer 做分割编码器） | 分割需要多尺度特征，CAFormer 的金字塔结构天然适配 U-Net / SegFormer 式解码器；很多医学分割工作直接拿它当 encoder | **不违规**，架构是通用工具 |
| **预训练权重**（ImageNet-22K + SAIL 蒸馏） | `timm/caformer_s18.sail_in22k_ft_in1k`，预训练数据是**通用自然图像** | **不违规** |
| 若换成**医学数据预训练的 CAFormer 权重** | 例如在胸片/CT 上自监督预训练过的版本 | **违规**（规则禁止医学预训练） |

**结论**：用 CAFormer 的**结构 + 通用 ImageNet 权重**没有问题；
不能用的是"在医学影像上预训练过的 CAFormer 权重"。
交付文档里应写明这一点，避免审核时被误判为医学预训练。

## 五、对我们这次训练的实际结论

1. **CAFormer 值得试的原因不是"更强"，而是"误差结构不同"**：
   现有三个 Tiny 之间相关性 0.95+，而供体（EfficientNet-B3，单独最弱 0.8129）与它们只有 0.82，
   却是贡献最大的成员（留一 −0.0041）。**多样性比个体强度更值钱。**
2. **接入成本可控**：stem 改单通道与 ConvNeXt 同型；末级 17×17 与我们一致，LSE 头可直接复用。
3. **预算上更推荐"换掉一个冗余 Tiny"而不是"再加一个成员"**：363 MB / ~83 ms，留一损失 0.0002~0.0006。
4. **验证路径不变**：fold 2、同配方 12 轮、通过线检查级宏 AUC ≥ 0.8200；
   另外加一条"多样性门槛"：与三个 Tiny 的平均 Spearman **< 0.90** 才值得进集成。
